# 云栖谷 · 景区婴儿车租借与清洁周转平台

景区婴儿车「借出 → 归还 → 清洁 → 安全复检 → 再借」全周转管理，含跨点归还、
维修工单、押金复核与缺车调拨提醒。纯 Python 标准库 + SQLite，零第三方依赖。

## 本地启动

```bash
python3 -m stroller.server --reset
# 打开 http://127.0.0.1:8000
```

`--reset` 重新写入演示数据（不加则沿用 data/stroller.db）。可选 `--host`/`--port`。

- 样例工号：`E01/E02` 普通员工（可借还、报修、清洁）；`M01/M02` 点位主管
  （安全复检、维修完工、押金复核）。顶栏可切换。
- 游客与付款均为样例：押金 ¥300 模拟预授权，付款回执以 `SIM-` 开头。
- 后台守护线程每 20 秒扫描超时单与缺车调拨需求，页面左下实时展示。

## 业务流程

```
扫码核验 → 资格（体重/库存/雨罩/刹车）→ 车辆轮廓检查（刹车·篷布·安全带·雨罩）
       → 锁定车辆+押金预授权 → 游客签署交车
归还复核（外观/附件/争议）→ 待清洁 → 清洁消毒完成 → 主管安全复检 → 可借
                      └ 异常/争议：押金冻结 → 主管押金复核（扣款后退余额）
任何状态可报修 → 维修中（禁借禁调拨）→ 主管完工 → 待清洁 → 复检 → 可借
```

关键规则：

| 场景 | 处理 |
|---|---|
| 体重超限 | 锁定步拒绝，引导选择更高承重车型 |
| 服务点缺车 | 两终端抢最后一辆：条件 UPDATE 裁决，仅一笔成功，输家无押金流水 |
| 雨罩缺失 | 禁止借出，车辆自动解锁，可报修补装 |
| 刹车异常 | 借出检查发现即挂维修、自动开工单 |
| 游客超时 | 超应还 15 分钟宽限，扣 ¥50 后退 ¥250；后台任务自动标记 |
| 跨点归还 | 归属位置变更；目标点满仓则拒绝并推荐可还点位 |
| 维修中车辆 | 禁止调拨，调拨提醒也不会推荐它 |
| 押金争议 | 押金冻结，主管复核决定扣除金额后退余额 |
| 重复归还 | 返回首次退款回执，标记幂等，绝不二次退款 |
| 权限 | 员工可报修/清洁；安全复检、维修完工、押金复核仅主管 |

## 存储

- SQLite：`data/stroller.db`
  - 状态表（vehicles/rentals/inspections/work_orders/payments/…）+
    事件流（vehicle_events/rental_events）双写，全程可追溯。
- 损伤照片：本地目录 `data/photos/`（multipart 上传，`/photos/<文件>` 访问）。
- 模拟适配器：`stroller/adapters.py`
  - 扫码：二维码格式 `VHC-<车辆编号>`（页面试试 `VHC-BADCODE` 看失败路径）；
  - 付款：退款按租借单 idempotency_key 幂等。

## 目录

```
stroller/
  db.py         SQLite schema（状态表 + 事件流）
  adapters.py   模拟扫码枪 / 支付回执（幂等）
  service.py    全部领域规则与事务
  seed.py       种子样例（缺车/跨点/刹车异常/争议/超时）
  server.py     HTTP JSON API + 静态页 + 进程内后台任务
web/            index.html / styles.css / app.js（景区白·森林绿·阳光黄）
tests/          领域规则测试
```
